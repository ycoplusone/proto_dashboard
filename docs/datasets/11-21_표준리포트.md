# 11 ~ 21 표준리포트 가상 ERP 데이터 — 정의서 (생성 완료)

> 2026-11-06 작성. 사용자 요청: "가상의 데이터로 회사에서 가장 보편적으로 하는 시각화(매출·회계·재무·경영·생산·인사 등 ERP)를 전체적으로 만들어 리포트 디자인과 분석 형태를 확인".
> 쓰는 곳: 메뉴 **표준리포트 › 경영 / 매출·영업 / 구매·재고 / 생산 / 회계 / 재무 / 인사** (분야마다 3개, 모두 21개 화면, `app_pages/std/`, 계산은 `utils/std.py`).
> 만드는 스크립트: `scripts/gen_erp.py` (11개 파일을 한 번에, seed 2026 고정). 파일끼리 숫자가 이어져야 해서 파일마다 스크립트를 나누지 않았다.

## 가상 회사

- 만들어서 파는 중견기업. 사업부 3개: **부품**(전장·기계부품, 1공장 L1~L3), **완제품**(생활·주방가전, 2공장 L4~L6), **상품**(사서 그대로 파는 소모품·공구).
- 2024-01 ~ 2025-12 (24개월). 연매출 약 1,000억 원, 직원 약 500명 (생산직 70%).
- 거래처 305곳, 영업사원 24명 (영업팀 4개), 품목 제품 72 + 상품 40 + 원자재 15, 공급사 16곳.
- 금액은 원 단위. 가공(마스킹)이 없는 가상 값이라 금액을 그대로 더하고 비교해도 된다.

## 파일끼리 이어지는 방식

- 판매(11) → 제품 출고(13) · 생산 계획(15) → 원자재 소요(제품마다 자재 2~4개, 원가의 50%) → 구매 발주(14) → 원자재 입고(13).
- 매출채권(17) = 거래처 × 월 매출(11) 합계, 말일 발행. 매입채무(17) = 공급사 × 입고월 입고금액(14).
- 자금수지(18) = 채권 회수·채무 지급(17) + 급여(20) + 판관비(16) + 제조경비 + 세금·설비투자·차입·이자·배당.
- 손익(16): 매출·매출원가 = 11, 판관비 급여 = 20(생산본부 부서는 매출원가에 들어 있어서 뺌), 영업외·법인세는 재무팀.
- 재무상태표(21): 현금 = 18 누계, 매출채권·매입채무 = 17 잔액, 재고 = 13, 이익잉여금 = 16 순이익 누계 − 배당, 차입금 = 18 차입·상환.
  **기타유동부채는 차액 조정 계정이다** (가상 데이터라 현금흐름과 손익이 정확히 맞지 않아서 자산 = 부채 + 자본이 되도록 여기서 맞춤, 160~233억 원).
- 2023년 말 채권·채무는 자료에 없다. 2024년 1~3월 자금수지에 '이전 잔액 회수·지급'을 추정해 넣었고, 2024년 초 채권 잔액은 실제보다 적게 보인다.

## 화면 규칙 (2026-11-06 정함)

- 차트는 숫자 카드·막대·선·표 4가지와 그 변형(워터폴, 파레토 = 비중 막대 + 누적 선, 누적 막대, 목표·예산 점선)만 쓴다. 파레토는 막대와 선이 같은 % 축이라 이중 축이 아니다.
- **기준월 하나를 고른다** (`utils/std.py`의 `pick_month`, `?month=2025-12`). 당월 · 1월 ~ 기준월 누계 · 작년 같은 달 · 작년 같은 기간을 그 달로 계산한다. 2024년 기준월은 작년 비교가 없다.
- 이름(영업사원·퇴사자)은 가상이지만 화면에서는 가운데 글자를 가린다 (`mask`).

## 확인할 것

- 패턴 강도는 사용자가 화면을 보고 정한다 (예: 초과근무와 이직률 연결은 1.3배로 약하다).
- 기타유동부채(차액 조정)가 크다. 재무상태표를 더 정교하게 맞출지는 사용자와 정한다.
