## 3. 심을 패턴 목록

해지 위험은 **월별 해지 확률**로 시뮬레이션한다. 아래 값은 기준 고객 대비 배수(위험비)이고, 각 배수를 곱해서 적용한다. 노이즈를 충분히 넣어서 해지 예측 정확도(AUC)가 0.70 안팎이 되게 맞춘다. 결과가 너무 깔끔하면 현실감이 없다.

| # | 패턴 | 설정값 | 확인할 시각화 / 마이닝 |
|---|---|---|---|
| P1 | **만료 시점 해지 집중** | 전체 해지 중 약 55%가 만료해지. 중도해지는 가입 후 첫 3개월에 위험 2배(설치 불만), 그 뒤로는 낮고 평평하게 | 생존 곡선의 계단 모양, 해지 위험 곡선, 유지개월 히스토그램 |
| P2 | **약정 길이 효과** | 24개월 약정은 중도해지 위험 0.6배. 만료 시 갱신율은 12개월 65%, 24개월 72% | 덤벨 차트, 약정별 생존 곡선과 log-rank 검정 |
| P3 | **결합상품은 해지를 막는다** | 해지 위험: 없음 1.0 · TV 0.75 · 모바일 0.6 · TV+모바일 0.45 | Cox 모델의 위험비, 100% 누적 막대 |
| P4 | **할인 효과** | 할인율 0%인 고객은 만료 시 갱신율 −10%p | 박스플롯, Cox 모델 |
| P5 | **상품 고도화 추세** | 1G 신규 비중: 2022년 15% → 2026년 35%. 갱신할 때 100M→500M 25%, 500M→1G 15%, 하향 5% | 생키, 전이 행렬, 누적 영역 |
| P6 | **연령대** | 해지 위험: 20대 1.4 · 30대 1.1 · 40대 1.0 · 50대 0.85 · 60대이상 0.7. 20대 해지사유는 이사와 경쟁사이동이 60% | 연령대×상품 히트맵, 선버스트 |
| P7 | **계절성 (이사철)** | 3월과 9월 해지 위험 1.5배(사유는 주로 이사). 신규 가입은 2~3월에 많음 | 캘린더 히트맵, 극좌표 차트, 월별 선 |
| P8 | **가입채널** | 온라인 가입은 해지 위험 1.3배. 방문영업은 첫 3개월 중도해지 위험 2.5배(불완전판매) | 채널별 생존 곡선, 알루비얼 |
| P9 | **지역 품질 문제** | 강원·전라남도는 품질불만 해지가 2배. 수도권은 경쟁사이동 사유 비중이 높음 | 시도 지도, 해지사유 트리맵 |
| P10 | **법인 고객** | 24개월 약정 80%, 1G 비중 40%, 해지 위험 0.5배 | 고객유형별 비교 막대, 군집화 |
| P11 | **요금 부담** | 실납부요금이 높을수록 `요금부담` 사유 비중 증가 | 산점도, 박스플롯 |
| P12 | **노이즈** | 위의 모든 효과에 고객별 무작위 요인을 곱함. 이유 없이 해지하는 고객 약 10% | 예측 모델 AUC 0.70 안팎 |

### 일부러 넣지 않는 것

- 행동 데이터(사용량·장애·상담)는 이 파일에 넣지 않는다. 02번과 03번 파일에서 다룬다.
- 시군구 단위 효과는 넣지 않는다. 시군구당 표본이 적어서 의미가 없다.

## 4. 검증 체크리스트 (데이터 생성 후)

- [ ] 상태가 해지(만료해지·중도해지)인 행에만 해지일과 해지사유가 있다
- [ ] 갱신 행 다음에는 같은 고객ID, 계약차수 +1, 시작일 = 직전 종료일 + 1일인 행이 있다
- [ ] 이전상품은 직전 계약의 상품과 같다
- [ ] 고객별 마지막 계약의 상태는 유지 / 만료해지 / 중도해지 중 하나다 (갱신이면 안 됨)
- [ ] 시작일·해지일·종료일 ≤ 기준일 (단, 유지 상태의 종료일은 기준일보다 뒤일 수 있음)
- [ ] 패턴 P1~P11이 집계했을 때 설정값 근처로 나온다

## 5. 확정 사항

사용자가 초안 그대로 확정했다 (2026-10-20).

- 고객유형: 개인 + 법인(10%)
- 결합상품: 포함
- 규모: 고객 5,000명
- 요금표와 해지사유 6종: 초안 그대로

## 6. 생성 결과 (seed 42)

- 고객 5,000명 / 계약 7,493건
- 상태별 건수: 유지 2,920 · 갱신 2,493 · 만료해지 1,211 · 중도해지 869
- 무결성 검증: 통과

| 패턴 | 목표 | 실제 |
|---|---|---|
| P1 해지 중 만료해지 비율 | ~55% | 58% |
| P2 만료 시 갱신율 (12개월 / 24개월) | 65% / 72% | 64% / 70% |
| P3 결합상품별 해지율 | 없음 > TV > 모바일 > TV+모바일 | 36% > 29% > 22% > 18% |
| P4 갱신율 (할인 0% / 할인 있음) | −10%p | 61% vs 69% (−8%p) |
| P5 신규 1G 비중 | 15% → 35% | 19% → 37% |
| P6 20대 해지사유 중 이사+경쟁사이동 | ~60% | 65% |
| P9 품질불만 비중 (강원·전남 / 기타) | 2배 | 25% vs 12% (약 2배) |
| P11 '요금부담' 비중 (요금 낮음 → 높음) | 증가 | 9% → 26% |
| P7 해지 월별 건수 | 3·9월 높음 | 3월 224, 9월 206 (다른 달 111~198) |
| P10 해지율 (개인 / 법인) | 법인 0.5배 | 29.5% / 14.7% |
| P12 속성 기반 해지 AUC | ~0.70 | 0.66 |

참고:
- P7: 10~12월은 2026년 데이터가 없어서 건수가 적다. 월별 비교는 연도별로 나누거나 비율로 봐야 한다.
- P12: 노이즈를 줄여도 AUC가 거의 오르지 않았다. 해지 여부 자체가 확률적으로 정해져서 생기는 한계다. 행동 데이터(02번 파일)를 더하면 오를 것으로 본다.
