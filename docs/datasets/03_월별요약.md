# 03_월별요약 — 컬럼 정의서

- 파일: `data/03_월별요약.xlsx` (시트 1개, 36행)
- 1행 단위: **1개월** (2023-01 ~ 2025-12)
- 만드는 법: `02_고객현황`을 월별로 집계한다 (`scripts/gen_03_monthly.py`). 따로 가상 데이터를 만들지 않으므로 02와 숫자가 항상 이어진다.
- 쓰는 곳: 현업용 월간 보고서 (`app_pages/report/monthly.py`)
- 상태: 확정 · 생성 완료 (2026-10-20)

## 설계 원칙

현업이 이미 엑셀로 보는 형태가 가장 쉽다. 모든 숫자는 "몇 명" 또는 "얼마"이고, 비율 컬럼은 두지 않는다.
