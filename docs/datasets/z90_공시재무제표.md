# z90_공시재무제표 — 데이터 정의서 (확정·생성 완료)

> 2026-11-03 작성. 사용자 확정: 4개 회사, 2023~2025년, 연결, 특정 회사 강조 없음. `scripts/fetch_dart.py`로 OpenDART에서 받아 `data/z90_공시재무제표.xlsx`를 만들었다.
> 쓰는 곳: 메뉴 **경쟁사 비교 > 수익성 비교** (`/finance-profit`, `app_pages/finance/profit.py`, 계산은 `utils/finance.py`).

- **목적:** 유료방송·인터넷 4개 회사의 수익성 비교 (리포트 '경쟁사 수익성 비교')
- **출처:** 금융감독원 전자공시(DART), OpenDART API. 공개 자료라 가공하지 않는다. API 키는 `.env`의 `OPENDART_API_KEY` (git 제외).
- **1행 단위:** 회사 × 연도 1개 (4개 회사 × 3년 = 12행)
- **기간:** 2023 ~ 2025 사업연도 (12월 결산)
- **재무제표:** **연결** 기준 (자회사 실적까지 포함. KT스카이라이프는 HCN이 연결에 들어간다)

## 화면에서 계산할 비율 (수익성 중심)

| 이름 | 계산식 | 답하는 질문 |
|---|---|---|
| 영업이익률 | 영업이익 ÷ 영업수익 | 매출 100원에서 영업으로 얼마 남기나 |
| EBITDA 마진 | (영업이익 + 감가상각비) ÷ 영업수익 | 설비가 큰 업종이라 감가상각을 빼고 본 현금 창출력 |
| 순이익률 | 당기순이익 ÷ 영업수익 | 이자·손상 등까지 뺀 뒤 남는 것 |
| 설비투자 비율 | 설비투자 ÷ 영업수익 | 매출 중 얼마를 다시 설비에 넣나 |
| 잉여현금흐름 | 영업활동현금흐름 − 설비투자 | 투자하고 남는 현금 |
| 부채비율 | 부채총계 ÷ 자본총계 | 재무 안정성 (보조) |
| 매출 증감 | 올해 영업수익 ÷ 작년 − 1 | 외형이 커지나 줄어드나 |

- 회사마다 규모가 10배 이상 달라서(SK브로드밴드 vs 딜라이브) 금액보다 **비율**로 비교한다.
- 비율은 "매출 100원 중 N원"으로 쓴다.

## 생성 결과와 점검 (2026-11-03)

- **만든 컬럼:** 회사, 사업, 연도, 영업수익_원, 영업비용_원(= 영업수익 − 영업이익), 영업이익_원, 당기순이익_원, 자산총계_원, 부채총계_원, 자본총계_원, 영업활동현금흐름_원, 접수번호. 12행.
- **뺀 컬럼: 감가상각비·설비투자.** 회사마다 계정이 같은 기준으로 맞지 않는다. SK브로드밴드·KT스카이라이프는 현금흐름표에 감가상각비 줄이 없고(주석에만 있음), KT스카이라이프 투자 줄에는 방송프로그램 취득이 섞여 있다. 그래서 EBITDA 마진·설비투자 비율·잉여현금흐름은 화면에 쓰지 않는다.
- **계정 코드가 다른 경우 (이름으로 찾음):** KT스카이라이프 2023·2024년 '영업수익'이 `ifrs-full_GrossProfit` 코드로 올라와 있다. LG헬로비전 2023년 재무상태표 '자본총계'는 표준 코드 미사용.
- **딜라이브 원문 읽기:** 연결감사보고서 앞쪽 30개 표에서 계정 이름으로 찾는다. 처음에 주석 번호 칸('34,36')을 금액으로 읽어 영업수익이 3,436원으로 나왔다. 금액은 천 단위 쉼표 형식만 인정하도록 고쳤다.
- **재작성 점검:** 각 연도 당기 값과 다음 해 보고서의 전기 값이 4개 회사 모두 같다 (딜라이브 원문 읽기도 이 점검으로 확인).
- **딜라이브 2025년:** 자본총계 −741억 원(자본잠식)이라 부채비율은 계산하지 않는다. 당기순손실 896억 원 중 영업권 손상차손이 641억 원이다 (연결감사보고서 무형자산 주석, 천 원 단위 64,131,467).
