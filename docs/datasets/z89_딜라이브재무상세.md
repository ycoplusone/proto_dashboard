# z89_딜라이브재무상세 — 데이터 정의서 (생성 완료)

> 2026-11-04 작성. 사용자 요청: "딜라이브만 더 다이나믹하게 분석" → 제안한 6개 화면을 모두 만들기로 함.
> 쓰는 곳: 메뉴 **딜라이브 재무 분석** (`app_pages/dfin/`, 계산은 `utils/dfin.py`). 만드는 스크립트: `scripts/fetch_dlive_detail.py`.

- **출처:** 금융감독원 전자공시(DART) 딜라이브 **연결감사보고서** 원문(document.xml) 13개. 공개 자료라 가공하지 않는다. API 키는 `.env`.
- **기간:** 2013 ~ 2025 사업연도 (연결감사보고서가 있는 해. 2012년 이전은 별도 감사보고서만 있음)
- **1행 단위:** 연도 × 항목 1개 (긴 표). 968행.
- **연도별 값:** 그 해 보고서의 당기 값 (다음 해 보고서가 고쳐 쓴 값이 아님). z90의 2023~2025년 값과 모두 같다.

## 읽는 방법과 점검 (2026-11-04)

- **글자 인코딩:** 2013~2021년 보고서 대부분은 EUC-KR(cp949)이다 (XML 머리에는 utf-8이라고 적혀 있음). utf-8로 안 되면 cp949로 읽는다.
- **2018년:** 정정 보고서(20190416000082)에는 원문 파일이 없어 원 보고서(20190410001118)를 쓴다.
- **본문 금액:** 쉼표 있는 숫자만 금액으로 본다 (2024년 '영업비용 29'처럼 주석 번호 칸을 금액으로 읽는 것 방지).
- **주석 표 고르기:** 합계가 본문 영업수익(영업비용)과 같은 표를 고른다.
- **2020~2022년 영업수익 주석**은 부문별 표라 합계가 본문과 맞지 않는다 (2020년은 PP·엔터가 중단영업으로 빠져 본문은 SO만, 주석은 전 부문). SO 열을 쓰고 차이를 '연결조정'으로 둔다 (2020년 −14억, 2021년 −2억, 2022년 0억).
- **재작성 점검 (다음 해 보고서의 전기 값이 다른 것):**
  - 2019년: 2020년 보고서가 아이에이치큐를 중단영업으로 다시 써서 영업수익 5,177억 → 4,250억 등 손익 항목 대부분이 다르다. 화면은 그 해 값(5,177억)을 쓰고 2015~2019년을 'PP·엔터 포함'으로 표시한다.
  - 2022년: 기타수익 463억 → 191억 (2023년 보고서부터 상품수익을 따로 적음). 그래서 상품과 기타를 합쳐 본다.
  - 2014·2020·2024년: 몇 개 항목에서 작은 재분류 (영업외 손익, 무형자산 취득 등).
- **z90과 맞춰 보기:** 2023~2025년 영업수익·영업이익·당기순이익·자산·부채·자본·영업활동현금흐름이 모두 같다.
