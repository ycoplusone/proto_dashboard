# z95_상담장애이벤트 — 요청 정의서 (데이터 받기 전)

- 상태: **요청** (2026-10-26)
- 우선순위: **3순위 (선택)**. 1·2순위로 리포트를 만든 뒤 받아도 된다.
- 파일: `data/z95_상담장애이벤트.xlsx` (100만 건이 넘으면 CSV)
- 1행 단위: **상담 또는 장애·AS 1건**
- 기간: **2024-10-01 ~ 2025-12-31 (15개월)**
  - 2025년 1월 해지 고객도 해지 전 3개월의 상담 이력을 볼 수 있게 2024년 10월부터
- 목적: "해지 전에 무슨 일이 있었나". 해지 고객(z97)과 남은 고객(z98)의 상담·장애 횟수 비교, 해지 대기 고객의 최근 불만

## 컬럼

| # | 컬럼 | 타입 | 설명 |
|---|---|---|---|
| 1 | EVT_ID | 문자 | 이벤트 번호 |
| 2 | CUST_ID | 문자 | 고객 번호 (z98·z97과 같은 체계) |
| 3 | CTRT_ID | 문자 | 계약 번호 (모르면 빈 값) |
| 4 | EVT_DT | 날짜 | 접수일 |
| 5 | DONE_DT | 날짜 | 처리 완료일 |
| 6 | EVT_TYPE | 범주 | 상담 / 장애 / AS / 민원 |
| 7 | EVT_RSN_L | 범주 | 사유 대분류 (예: 요금, 품질, 이사, 해지문의) |
| 8 | EVT_RSN_M | 범주 | 사유 중분류 |
| 9 | CHANNEL | 범주 | 전화 / 방문 / 온라인 등 |
| 10 | RESULT | 범주 | 처리 결과 (해결 / 미해결 / 해지방어 성공 / 해지방어 실패 등) |
| 11 | SO_NM | 범주 | z98과 같은 표기 |
| 12 | BIZ_CL | 범주 | I / D |

- 상담 내용(자유 텍스트)과 상담원 이름은 넣지 않는다.
